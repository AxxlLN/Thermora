# Thermora

**Thermora** — модульное инженерное приложение для расчёта и анализа тепловых режимов радиоэлектронной аппаратуры.

Приложение предназначено для оценки температурных характеристик электронных устройств и их конструкций, исследования условий теплообмена и сравнения различных расчётных методик.

В основе Thermora лежит независимое вычислительное ядро на **Kotlin/JVM**, отделённое от пользовательского интерфейса и инфраструктуры. Архитектура предусматривает использование ядра в настольном приложении и через серверный API.

Thermora поддерживает концепцию двух типов физических моделей: **Legacy** — воспроизведение существующих методик расчёта, и **Improved** — отдельные реализации с уточнёнными физическими зависимостями и документированными условиями применимости.
